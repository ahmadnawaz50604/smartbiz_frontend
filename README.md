# SmartBiz Frontend
Static site (HTML/CSS/JS) for the SmartBiz API. No build step.
1. Edit `config.js` -> set `API_BASE` to your backend URL.
2. Push to GitHub, import in Vercel (Framework: Other), Deploy.
3. In the backend Vercel project, set env var FRONTEND_ORIGIN to this site's URL and redeploy (optional hardening).
